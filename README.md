1. Project Name: Coffee Shop website

2. Project description: Web development project meant to be used as practice for basic HTML and CSS.

3. Techniques and Technologies: Development of a landing page project for a coffee shop using technologies such as HTML, CSS, GIT and GITHUB. This practice is meant to exemplify the understanding of the following:

a. HTML structure and nesting of elements, as well as usage of semantic HTML tags to facilitate SEO integration.
b. CSS styling as per UX/UI pre-established guidelines in regards to font and color palette, as well as effective usage of flexbox for element distribution.
c. Git/GitHub integration to the workflow to demonstrate understanding of their basics.

1. Nombre del Proyecto: Página web de una cafetería

2. Descripcion del Proyecto: Proyecto de desarrollo web que tiene la intencion de servir como practica de las bases de HTML y CSS.

3: Tecnicas y tecnologias: Desarrollo de una página de Inicio (Landing page) para una cafetería utilizando tecnologías como HTML, CSS, GIT y GITHUB. Esta práctica pretende ejemplificar la comprensión de los siguientes aspectos:

a. Estructura HTML y anidación de elementos, así como el uso de etiquetas HTML semánticas para facilitar la integración SEO.
b. Estilo CSS según las directrices preestablecidas de UX/UI en cuanto a fuente y paleta de colores, así como el uso eficaz de flexbox para la distribución de elementos.
c. Integración de Git/GitHub en el flujo de trabajo para demostrar la comprensión de sus fundamentos.
