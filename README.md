Web development project meant to be used as practice for basic HTML and CSS.

- Development of a landing page project for a coffee shop using technologies such as HTML, CSS, GIT and GITHUB. This practice is meant to exemplify the understanding of the following:

1. HTML structure and nesting of elements, as well as usage of semantic HTML tags to facilitate SEO integration.
2. CSS styling as per UX/UI pre-established guidelines in regards to font and color palette, as well as effective usage of flexbox for element distribution.
3. Git/GitHub integration to the workflow to demonstrate understanding of their basics.

/////// SPANISH ////////////////////////////////////////////////////////////////////////////////////////////////////

Proyecto de desarrollo web que tiene la intencion de servir como practica de las bases de HTML y CSS.

- Desarrollo de una página de Inicio (Landing page) para una cafetería utilizando tecnologías como HTML, CSS, GIT y GITHUB. Esta práctica pretende ejemplificar la comprensión de los siguientes aspectos:

1. Estructura HTML y anidación de elementos, así como el uso de etiquetas HTML semánticas para facilitar la integración SEO.

2. Estilo CSS según las directrices preestablecidas de UX/UI en cuanto a fuente y paleta de colores, así como el uso eficaz de flexbox para la distribución de elementos.

3. Integración de Git/GitHub en el flujo de trabajo para demostrar la comprensión de sus fundamentos.
